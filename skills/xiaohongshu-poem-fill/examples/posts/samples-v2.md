## 1. 诗｜五言绝句｜山窗夜坐

标题：诗词填空｜山窗夜坐，这四个字你会怎么点？

正文：

山月（　）松窗，  
溪云（　）石床。  
茶烟（　）书卷，  
秋声（　）短廊。

这条我故意把四句都留了一个字，适合评论区逐句接龙。你会先补哪一句？

推荐答案参考：

1. `照`
2. `过`
3. `染`
4. `满`

备选方向：

1. `映` `入`
2. `绕` `落`
3. `熏` `侵`
4. `到` `过`

话题：`#诗词填空` `#五言绝句` `#古风短句` `#画龙点睛挑战` `#中文之美`

## 2. 诗｜五言绝句｜江桥晚归

标题：古风填空｜晚归这一组字，你会填得更清冷还是更温柔？

正文：

残照（　）汀沙，  
归舟（　）蓼花。  
渔灯（　）远渚，  
秋水（　）寒鸦。

这一条更偏江岸晚景，每句都能填出不一样的风味。欢迎把你的一整版答案也写出来。

推荐答案参考：

1. `落`
2. `过`
3. `照`
4. `送`

备选方向：

1. `映` `染`
2. `穿` `入`
3. `临` `映`
4. `带` `惊`

话题：`#诗词填空` `#五言绝句` `#江上归舟` `#国风笔记` `#中文之美`

## 3. 诗｜五言绝句｜雪檐夜读

标题：诗词填空｜冬夜书窗前，这四个字你会怎么落？

正文：

梅雪（　）疏檐，  
清寒（　）砚奁。  
孤灯（　）旧字，  
茶气（　）重帘。

这一条适合做冬夜氛围感，四句都偏静，评论区一般会出现很好看的细微别解。

推荐答案参考：

1. `压`
2. `入`
3. `照`
4. `透`

备选方向：

1. `映` `满`
2. `侵` `染`
3. `临` `映`
4. `侵` `度`

话题：`#诗词填空` `#五言绝句` `#冬夜诗意` `#书窗雪意` `#古风短句`

## 4. 词｜小令风｜春晓小院

标题：词里填空｜这组春晓小院，你会把哪几个字补活？

正文：

薄雨（　）帘初晓，  
轻烟（　）柳成阴。  
小桥（　）水到门，  
燕子（　）花深处。  
归梦（　）江南路，  
愁心（　）一枝春。

这一条是小令风写法，适合让大家按整组气息来填，不一定只盯着单句。

推荐答案参考：

1. `入`
2. `锁`
3. `带`
4. `穿`
5. `到`
6. `寄`

备选方向：

1. `侵` `湿`
2. `笼` `染`
3. `分` `牵`
4. `惊` `过`
5. `绕` `归`
6. `付` `托`

话题：`#词里填空` `#小令风` `#古风短句` `#春日氛围` `#中文之美`

## 5. 词｜短章｜夜雨小阁

标题：画龙点睛挑战｜夜雨小阁这几句，你会先填哪一个字？

正文：

小阁（　）灯听夜雨，  
旧笺（　）墨记春山。  
风帘（　）月过栏杆，  
梦里（　）舟下远滩。

这条更适合做偏文艺一点的评论互动，四句的空都比较有动作感。

推荐答案参考：

1. `挑`
2. `和`
3. `带`
4. `移`

备选方向：

1. `背` `临`
2. `调` `染`
3. `卷` `弄`
4. `系` `送`

话题：`#词里填空` `#夜雨氛围` `#古风文案` `#画龙点睛挑战` `#小红书国风`

## 6. 词｜短章｜江天归棹

标题：古风填空｜归棹月夜这四句，你会补出怎样的水意？

正文：

月下（　）轻舟慢，  
潮声（　）客梦长。  
雁影（　）天将曙，  
灯痕（　）水乍凉。

这一条更偏清冷空阔，适合让评论区出现很多“同景不同情”的答案。

推荐答案参考：

1. `送`
2. `入`
3. `横`
4. `照`

备选方向：

1. `载` `引`
2. `和` `带`
3. `过` `分`
4. `映` `落`

话题：`#词里填空` `#月下归舟` `#古风填词` `#中文之美` `#小红书文案`
