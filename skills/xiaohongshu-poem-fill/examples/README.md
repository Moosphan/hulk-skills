# Examples

This directory provides concrete examples for the `xiaohongshu-poem-fill` skill.

## Posts

- `posts/samples-v2.md`
  - 6 mixed poem and ci-style Xiaohongshu post examples
  - each line contains a single-character blank
  - includes links to matching cover images
- `posts/samples-v3-tang-song.md`
  - 40 expanded examples inspired by Tang poetry and Song ci aesthetics
  - 10 five-character jueju and 30 ci-style pieces
  - each card contains exactly 2 single-character blanks on different lines
