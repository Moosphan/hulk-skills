# 长版日报结构（对标白鸦 2026-11-06 拆解）

> 目标：3–4 分钟；主线 4–6 条，每条 35–45 秒；顶部快讯 6 条；每条主线 ≥3 个视觉面板。

## 时间轴模板
| 段 | 时长 | 内容 |
|---|---|---|
| 开场 | 8–12s | 一句话点出今天 3–4 条主线，不报日期 |
| 快讯 | 15–25s | 6 条，每条一句 + 来源名，屏幕列表呈现 |
| 主线 ×N | 各 35–45s | 能力 → 数字 → 使用条件/价格，三层讲透 |
| 榜单 | 15–20s | Tibo 重置 + 能力/使用量/价格三列 |
| 收尾 | 3–5s | 一句收口 |

## 每条主线的口播三层
1. **是什么**：一句话结论 + 型号/版本
2. **数字**：1–3 个可核验指标（benchmark、价格、限额、时长）
3. **边界**：谁能用、怎么用、限制是什么（访问门槛/许可/未官方）

## 顶部快讯选择
- 6 条，覆盖不同类别：编程工具、开源权重、基础设施、人事、使用量、传闻
- 每条必须有一手链接（官方 blog / X 原帖 / 工程博客），不写媒体转述
- 屏幕上前 6 秒不展开，一句话带过

## 简介格式（必须有）
```
<一句话概括今天的主线>

来源：
OpenAI <官方 URL>
Claude <官方 URL>
...
视频章节
00:00 开场
00:19 <主线 1>
...
顶部快讯
<快讯 1>（来源）<URL>
...
```

## 质量闸门
- 主线 <3 条 → 不叫日报，改叫快讯
- 任一主线面板 <3 个 → 补素材或降级为快讯
- 口播只有形容词没有数字 → 重写
- 快讯没有一手链接 → 换一条
