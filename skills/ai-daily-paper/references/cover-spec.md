# 封面规范（所有日报形式统一，2026-11-05 定稿）

适用于：早报（浅色）、晚报（深色）、插播/晚间增量（深色）、番外。
**一律用生成器产出，禁止手写坐标、禁止每次重排。**

## 生成器
```bash
python3 templates/cover/cover.py config.json
# 输出 <out>-169.jpg（1920×1080）与 <out>-43.jpg（1440×1080）
```

## 4:3 版
- 同一 config，`sc_override=0.86`
- 卡片按宽度等分，自动换行不溢出
- 字号随 scale 缩放，不裁 16:9

## 硬规则
1. 封面必须有：报头、日期、**账号名**、主标题、型号/数据关键词、厂商 logo、底部 3 卡
2. 关键词必须做成贴纸/红块，**型号 ≥78px、数据点 ≥60px**
3. logo 用产品 logo（Claude 星芒、OpenAI 花瓣），贴纸式白描边 + 淡阴影
4. 不放头像
5. logo 之间保持 ≥200px 间距，错落摆放
6. 深色主题下 logo 描边用深色（#1C1610），白底 logo 需换成浅色版本
7. 产出一律 16:9 + 4:3 两张，随成片和发布信息一起交付

## 自动校验（生成器内置）
- logo 之间不得重叠：生成器计算包围盒，重叠直接 `LOGO_OVERLAP` 退出
- logo 不得超出右边界：`LOGO_OVERFLOW` 退出
- 空间不足时按比例缩小 logo，不挪位置压字
- 4:3 版 logo 放在 y=0.50H 的下半区，避免压主标题
- 出图后必须人工过一眼：logo 不压字、不压卡片、间距 ≥40px


## 标题与间距硬规则（2026-11-06）
1. **标题必须含主语**：公司名或产品名（`OpenAI 收购 Pierre`、`腾讯混元 Hy4`、`百度文心 5.5`），禁止只写动作或数字（`收购 Pierre`、`280B 开源` 都不合格）
2. 主语放标题最前，动作在后；版本号可以省略到副标
3. **logo 不得压字**：生成器会算标题/关键词/副标的包围盒，与 logo 包围盒相交时自动下移，并留 ≥48px 安全距
4. logo 右对齐、单行并排，总宽超出可用区时按比例缩小，不往左挤
5. 4:3 版：logo 放 y=0.56H 下半区，尺寸 ×0.85
6. 出图后仍要过一眼：标题、关键词块、副标、logo、三卡五项互不重叠


## 海报版式（同行对标，2026-11-06 起优先）
- 参考同行：**3–5 个巨型字 + 1 个关键词块 + 大 logo**，不放三卡、不放长副标
- 标题拆两行：主语 190px（OpenAI / 腾讯混元 / 百度文心），动作 130px（收购 Pierre）
- 只保留 1 个关键词块（84px 白字橙底）
- logo：主 400px、次 200–250px，右半区错落，不压字
- 版面允许 >60% 留白，宁少不多
- 副标只在必须解释版本号时保留一行 30px

## 官方 logo 来源（2026-11-06 起）
- 统一从 thesvg 取：`https://cdn.jsdelivr.net/gh/glincker/thesvg@main/public/icons/<name>/default.svg`
- 已用：openai、baidu、moonshot（Kimi/月之暗面）、tencent、claude、anthropic、google
- 深色封面把 logo 转白：`Image.merge('RGBA', (*invert(rgb).split(), alpha))`
- 生成 PNG：Playwright 打开本地 HTML 截 `img`，`omitBackground:true`，2x
- 大尺寸：主 logo 380–430px、次 240–300px；两枚右对齐、间距 ≥36px，不裁切、不压字

## 单 logo + 文字标签（2026-11-06）
- 第二条新闻的厂商 logo 找不到可靠官方素材时，**不要拿错图**：改用橙色描边文字标签（如 `Kimi K3.1 Pro 开源`）
- 主 logo 用官方 SVG 放大到 520px，独占右半区
- 文字标签放在右下，橙色描边、透明底，字号 46px

## 模型没有独立 logo 时（2026-11-07）
- 先查官方发布页的 og:image / cover-social，常有该模型的**官方视觉母题**（如 Inkling 的墨迹线稿）
- 用「官方母题 + 公司字标」组合，而不是只放公司名
- 公司字标可直接从官网 header 截取，做 alpha 抠字（浅底→深字、深底→白字）
- 两者上下分区摆放：母题在上、字标在下、第二条新闻用橙色描边文字标签，三层不重叠

## 间距强制校验（2026-11-08）
`poster.py` 已内置：标题/副标/关键词块的右边界 +56px 才是 logo 起始位置，放不下则按 0.92 等比缩小，18 次仍放不下直接 `LOGO_TOO_CLOSE` 报错退出。

## logo 素材规范（2026-11-10 事故）
- 必须用 **透明底 PNG/SVG**，禁止用网页截图裁剪（会带白底、会截断边缘）
- thesvg 的图标 SVG 多为 `fill` 单色 + 镂空字形；直接渲染会得到"黄底透明字"，需要把镂空区填成品牌黑（#1A1A1A）再导出
- 严禁从二维码、海报、视频截图中抠 logo
- 出图前检查四角：背景必须是透明或纯纸色，不能有白框
