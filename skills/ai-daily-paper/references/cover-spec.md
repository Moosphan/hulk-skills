# 封面规范（所有日报形式统一，2026-11-05 定稿）

适用于：早报（浅色）、晚报（深色）、插播/晚间增量（深色）、番外。
**一律用生成器产出，禁止手写坐标、禁止每次重排。**

## 生成器
```bash
python3 templates/cover/cover.py config.json
# 输出 <out>-169.jpg（1920×1080）与 <out>-43.jpg（1440×1080）
```

## 版式（16:9 基准）
| 元素 | 位置 | 规格 |
|---|---|---|
| 左侧竖条 | x=0，宽 16 | 主题色（浅色 #B23A2E / 深色 #B23A2E） |
| 报头 | (96,50) | 54px 宋体 |
| 日期 | (98,118) | 26px 苹方 |
| 账号名 | 右上 (W-96,56) 右对齐 | 34px + 6px 红点 |
| 主标题 | (92,160) | **170px** 主题色 |
| 型号贴纸 | (96,395) | **96px** 黑字 + 10px 白描边 |
| 数据点红块 | y=560，从 x=96 横向排列 | 78px 白字，块内边距 20×12，块间距 70 |
| 副标 | (98,700) | 32px 灰 |
| logo | 主 (0.56W,0.13H)，次 (0.755W,0.44H) | 主 330 / 次 210，贴纸：白描边 49px、阴影 opacity 0.26 |
| 底部三卡 | 底边距 75，等分三段 | 高 125，标签 24px、正文 32px |

## 4:3 版
- 同一 config，`sc_override=0.86`
- 卡片按宽度等分，自动换行不溢出
- 字号随 scale 缩放，不裁 16:9

## 硬规则
1. 封面必须有：报头、日期、**账号名**、主标题、型号/数据关键词、厂商 logo、底部 3 卡
2. 关键词必须做成贴纸/红块，**型号 ≥78px、数据点 ≥60px**
3. logo 用产品 logo（Claude 星芒、OpenAI 花瓣），贴纸式白描边 + 淡阴影
4. 不放头像
5. logo 之间保持 ≥200px 间距，错落摆放
6. 深色主题下 logo 描边用深色（#1C1610），白底 logo 需换成浅色版本
7. 产出一律 16:9 + 4:3 两张，随成片和发布信息一起交付

## 自动校验（生成器内置）
- logo 之间不得重叠：生成器计算包围盒，重叠直接 `LOGO_OVERLAP` 退出
- logo 不得超出右边界：`LOGO_OVERFLOW` 退出
- 空间不足时按比例缩小 logo，不挪位置压字
- 4:3 版 logo 放在 y=0.50H 的下半区，避免压主标题
- 出图后必须人工过一眼：logo 不压字、不压卡片、间距 ≥40px
