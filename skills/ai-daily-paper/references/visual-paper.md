## 版式网格

- 画布 1920×1080，左右边距 64，页眉线 top 150
- 报头：`AI 日报/晚报` 宋体 86，字距 12–18
- 页眉：品牌 + 期号，**字号 ≥22**
- 正文标题：宋体 Black 64–76，行高 1.2
- 正文要点：黑体 32–36，行高 1.6
- 底部：分段进度条 + 章节名（居中、常驻）+ 页脚

## 必备组件

1. **报头**：日期 / 刊名 / 期号 / 双细线
2. **三栏要闻**：编号 + 品牌 + 标题 + 一句摘要 + 超大淡数字
3. **引证卡**：原文引证 + 出处 + chips + 为什么重要（不贴第三方网页截图）
4. **榜单页**：Tibo 重置 + 能力榜 + 使用量榜 + 价格榜，每榜前六，带来源与日期
5. **进度条**：分段，文字常驻居中，不用等走到才显示

## 动效

- 报头横线从左展开（0.4s）
- 标题逐行遮罩上推
- 引证卡轻微旋转落位 + 印章弹性
- 榜单四块按旁白依次点亮（其余 55% 可见度）
- 片头头像：旋转虚线环 + 轻浮动；不要给头像加标签

## 品牌资产

- 头像：`public/brand/avatar.png`
- Logo：`public/logos/`（openai / claude.png / gemini.png / deepseek / qwen-dark / zhipu / minimax / meituan / kioxia）
- Logo 一律透明背景、彩色；深色底上不用纯白标

## 封面规格（必须两版都出）

| 比例 | 尺寸 | 用途 |
|---|---|---|
| 16:9 | 1920×1080 | B 站默认封面 |
| 4:3 | 1440×1080 | B 站首页推荐 crop |

规则：
1. 两版都必须**独立排版**，不许用 16:9 居中裁剪出 4:3。
2. 头像 + 昵称在右侧栏**竖直居中**（头像中心 = 画布中线），昵称在头像下方居中。
3. 主标题、日期、三条摘要全部在安全区内：左右 ≥5% 边距，上下 ≥6%。
4. 4:3 标题字号按画布高度重算，不能直接沿用 16:9 字号。
5. 出图后逐张目检：文字不裁、头像不偏、留白均衡。

## 封面规范（2026-11-03 定稿）

## 证据窗口（2026-11-04，不改版式）
- 版式保持报纸深/浅色不变
- 有原文素材时，在右下开一个「证据窗口」覆盖当前版面：宽 860、高 600、2px 描边、投影
- 素材用 `object-fit: cover; object-position: top`，只放新闻相关片段（标题 + 首段），不放整页
- 窗口底部压来源条（域名/媒体名）
- 同场景原有的「原文引证」文字卡自动隐藏，避免双卡
- 窗口出现时机与旁白对齐：场景开始后 0.3s 淡入
- 无截图时才回退到文字引证卡

## 截图裁剪
- 截 `article/main` 元素后，只保留顶部 700–800px（标题+导语+首段）
- 自动删除含 “free trial / subscribe / newsletter / cookie” 的推广块
- 弹窗必须先点掉，再截图

## 证据窗口形态（2026-11-04 实现）
`VideoPaperPM` 的 `s.evidenceType` 支持三种：

| 类型 | 字段 | 用途 |
|---|---|---|
| image（默认） | `evidence: 'evidence/x.png'` | 原文截图、X 卡、产品图 |
| video | `evidenceType:'video'`, `evidence:'evidence/video/x.mp4'` | 滚动录屏、演示片段 |
| card | `evidenceType:'card'`, `cardLabel/cardTitle/cardBody` | changelog、release notes、代码 diff |

规则：
- 视频卡高度 440，静音播放，`object-fit: cover`
- 卡片用深底 + 等宽字体，最多 6 行
- 三种形态都保留来源条 + 「证据」角标
- 录屏用「逐帧截图 + ffmpeg 合成」，不要依赖 Playwright recordVideo（headless 常拍出空白）
- 录制前先关 cookie 弹窗

## 证据卡阴影（2026-11-05）
- 证据卡（原文引证 / 证据窗口）**不加投影**，避免和 X 卡、截图自身的边界打架
- 需要卡片感时，只保留 1px 描边 + 纸色底
- X 帖子卡在渲染阶段就要关掉 `box-shadow`，不要指望外层遮住

### 贴纸阴影的真正透明度（2026-11-05 踩坑）
- `Image.putalpha(mask)` 是**替换** alpha，不是相乘；直接 `RGBA(0,0,0,alpha)` + `putalpha(outline)` 会得到不透明黑边
- 正确写法：
  ```python
  sh = Image.new('RGBA', size, (0,0,0,255))
  sh.putalpha(outline.point(lambda v: int(v * opacity)))  # opacity 0.10
  ```
- 封面贴纸当前参数：白描边 49px，阴影 opacity 0.26，偏移 3%、模糊 3.5%（0.10 几乎看不见，0.30 偏重，0.26 刚好）
