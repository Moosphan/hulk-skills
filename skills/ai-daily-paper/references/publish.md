# L5 发布层：B 站发布与复盘

## 硬门槛：没有「发」字，绝不发布

- 成片必须先发主人看；**只有主人明确回「发」才能调用 publish**
- 不得因为“内容已确认/时间紧/流程说可以直接发”就自行发布
- 发布前在会话里复述：BV 待生成、标题、封面、时长，等确认
- 违反即事故：立即报告，并尝试删除（删除需人机验证，通常需主人手动删）

## 先审题、后成片（默认）

- 晚报：**采集完先发选题清单**（S/A/B 分级），确认后再生成并直接发布
- 不再单独发成片确认；除非主人要求
- 早报：按 09:00 前发布执行
- 口令：「可以」→ 生成并发布；「删/换」→ 调整清单

## 发布

```bash
catbus bilibili item publish -a main --video <mp4> --title "..." --cover <png> --tid 231
```

- 分区：231 计算机技术
- 封面：16:9 + 4:3 各一张
- 标题：`AI 早报｜` / `AI 晚报｜` + 一句主张（≤30 字）
- 简介：三条要点 + 来源列表
- 发布后置顶评论：时间线

## 标题模板

- `AI 早报｜GPT-6.2 与 Claude 5.5 同一天曝光`
- `AI 晚报｜Tibo 又重置了，Codex 额度这周还能再领`

## 复盘

发布 2 小时后记录：播放、点赞率、评论、完播。
写入 `~/dsh-video-remotion/报告/日报复盘-YYYY-MM-DD.md`，重点看：

1. 封面点击率（换标题/封面前后对比）
2. 前 15 秒留存（片头是否太长）
3. 榜单页是否被拖拽/跳出
