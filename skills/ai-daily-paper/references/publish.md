# L5 发布层：B 站发布与复盘

## 硬门槛：没有「发」字，绝不发布

- 成片必须先发主人看；**只有主人明确回「发」才能调用 publish**
- 不得因为“内容已确认/时间紧/流程说可以直接发”就自行发布
- 发布前在会话里复述：BV 待生成、标题、封面、时长，等确认
- 违反即事故：立即报告，并尝试删除（删除需人机验证，通常需主人手动删）

## 先审题、后成片（默认）

- 晚报：**采集完先发选题清单**（S/A/B 分级），确认后再生成并直接发布
- 不再单独发成片确认；除非主人要求
- 早报：按 09:00 前发布执行
- 口令：「可以」→ 生成并发布；「删/换」→ 调整清单

## 发布

```bash
catbus bilibili item publish -a main --video <mp4> --title "..." --cover <png> --tid 231
```

- 分区：231 计算机技术
- 封面：16:9 + 4:3 各一张
- 标题：`AI 早报｜` / `AI 晚报｜` + 一句主张（≤30 字）
- 简介：三条要点 + 来源列表
- 发布后置顶评论：时间线

## 标题模板

- `AI 早报｜GPT-6.2 与 Claude 5.5 同一天曝光`
- `AI 晚报｜Tibo 又重置了，Codex 额度这周还能再领`

## 复盘

发布 2 小时后记录：播放、点赞率、评论、完播。
写入 `~/dsh-video-remotion/报告/日报复盘-YYYY-MM-DD.md`，重点看：

1. 封面点击率（换标题/封面前后对比）
2. 前 15 秒留存（片头是否太长）
3. 榜单页是否被拖拽/跳出

## 晚间增量发布（2026-11-04）
- 标题前缀：`【AI晚报·晚间增量】`
- 分区：`--category 201`（科学科普）
- 封面：取正片 5s 处含「正式发布」标题的帧，`ffmpeg -ss 5 -frames:v 1`
- 简介必须写：
  - 时长 + 时间节点
  - 证据来源（官方页面 / 官方演示视频 / benchmark）
  - 增量门禁说明：本次 N 条，是否 P0 例外
- 发布后回填 BV、时长、条目，并置顶时间节点评论
- 增量门禁未通过且非 P0：不发视频，改文字动态

## 双封面发布（强制，2026-11-04）
B 站允许横版 16:9 与竖版 4:3 两张封面。每次发布**必须同时上传两版**。

### 发布前自检
```bash
node ~/self-projects/catbus/dist/cli/main.js bilibili item publish --help | grep -i cover
```
- 若同时出现 `--cover` 与 4:3 专用参数（如 `--cover-43` / `--cover43`）→ 两版都传
- 若只有 `--cover` → 说明本地 catbus 未包含双封面 PR：
  1. 先切到对应 PR 分支并 `pnpm build`
  2. 再发布；不允许只传 16:9 就发

### 命令模板
```bash
node ~/self-projects/catbus/dist/cli/main.js -a main bilibili item publish \
  --video <成片.mp4> \
  --cover <16x9.jpg> \
  --cover-43 <4x3.jpg> \
  --title "..." --text @desc.txt --category 201 --tag ...
```
（4:3 参数名以 `--help` 实际输出为准）

### 交付包对应关系
| 文件 | 用途 |
|---|---|
| `xxx-封面16x9.jpg` | `--cover` |
| `xxx-封面4x3.jpg` | 4:3 专用参数 |
| `xxx.mp4` | `--video` |

只交一张封面 = 未完成。

## 发布前置确认（硬门禁，2026-11-05）
- **任何情况下**，发布前必须让主人确认：成片、16:9 封面、4:3 封面、标题、简介
- 定时任务（07:30 早报 / 19:00 晚报）只做到「待确认」：把成片和封面发出来，等主人回「发」
- 只有主人明确回「发 / 可以发布」才允许调用 publish
- 违规处理：立即把稿件设为 private（`item edit --video ... --visibility private`），并告知主人
