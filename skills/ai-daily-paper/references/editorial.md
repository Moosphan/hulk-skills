# L2 编辑层：选题、排序、口播

## 选题权重

| 维度 | 权重 |
|---|---|
| 影响面（多少开发者/用户受影响） | 30 |
| 新鲜度（窗口内首发） | 25 |
| 信息增量（有没有新参数/价格/能力） | 25 |
| 可验证性（有一手证据） | 20 |

同分时：国内模型优先（差异化），其次有明确数字的。

## 一期结构

```
片头（10s）：一句主张 + 日期
概览（12s）：3–4 条要点
正文：3 条深讲（每条 20–25s）+ 3–7 条快讯（每条 6–10s）
榜单页（20–28s）：Tibo 重置 + 能力榜 + 使用量榜 + 价格榜
片尾（5s）：头像 + 明日再见
```

条目数：**常规 6 条，重大事件多可到 10 条**，少于 6 条需在脚本里说明原因。
主题覆盖：模型/产品、基础设施、能源、芯片供应链、资本、政策安全、开源学术，至少跨 3 类。

## 口播规范

- 每句 ≤ 28 字，一句一个信息点
- 数字读法：`6.2` 读「六点二」，`1.6T` 读「一点六万亿」
- 不用「据悉/业内人士」；直接说谁说的
- 爆料必须口播「还没官宣」
- speed 0.95，句间留 0.2–0.3s

## 先审题、后成片（晚报默认）

1. 采集完成后，先产出**资讯清单**发给主人，不直接做视频。
2. 清单格式：

```
【今日 AI 晚报 · 选题清单】
S 级（必讲，深讲 2–3 cue）
1. 事件一句话｜来源｜时间｜证据类型
A 级（快讯，1 cue）
2. ...
B 级（备选，可删）
3. ...

共 N 条，覆盖 X 类；建议成片 M 秒。
```

3. 主人回「可以/发」后再写稿、配音、渲染；要删要换直接说。
4. 选题清单确认后不再单独确认成片，直接发布（除非主人另说）。

## 去重

- 早报讲过的，晚报只在有更新时提，并标「更新」
- 同一事件不跨期重复讲两遍
