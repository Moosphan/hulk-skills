# 文件与链接

本地文件以 FFmpeg 支持的容器/编码为准，如 WAV、M4A、MP3、FLAC、MP4、MOV、MKV、WebM。取第一个音频流。没有音轨会明确报错，不覆盖原文件。

B站公开 BV 视频及其 `?p=` 分P、`/bangumi/play/ep...` 和 b23 短链走公开接口，选择最高带宽的可用音频流。只获取指定条目，不自动下载合集。访问限制、DRM、仅试看内容会停止；不推断当前用户已登录或拥有会员权限。

其他 HTTP(S) 链接通过 yt-dlp；支持的平台随其版本变化，不能承诺任意网页都能下载。先运行 `setup --component download`。yt-dlp默认下载指定视频的最佳可用音频/媒体，后续由 FFmpeg 统一抽音轨。

用户明确提供已授权的 Netscape cookie 文件时可传 `--cookies path/to/cookies.txt`，使用 yt-dlp；无需也不应自动搜集浏览器 cookie 或把凭证写进报告。cookie 仍不能解密 DRM，也不代表能访问用户无权限的资源。不要在日志或回复中展示签名媒体 URL、cookie 内容。

对无法访问的来源，先报告具体错误并继续支持用户已有的本地文件，不用切换地区、伪造登录或无限重试。下载与模型处理都在本机进行；模型首次准备和在线媒体获取需要网络，转写/处理用户音频不上传到外部推理服务。
