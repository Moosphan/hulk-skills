# 视觉规范 · 深海夜光 + 物件库

> SKILL.md §2 的展开版。新集一律按本文执行。

## 1. 画布与栅格

- 1920×1080 / 30fps。安全边距：左 96、右 96、上 44、下 100。
- 人物占据右侧 1/3（x ≈ 1180–1920），左侧 2/3 是信息区。
- 标题区：`left: 96, top: 110–190`；内容区：`top: 240–760`；字幕：`top: 872`；片尾三连：`500–700`。
- 字体：标题 `Songti SC` 700；正文 `PingFang SC`；数字/代码 `SF Mono`。

## 2. 深海夜光背景（固定）

```tsx
// 底色
background: linear-gradient(175deg, #0A1322 0%, #05080F 62%, #03060C 100%)

// 光柱 ×4
left: {0.16,0.42,0.72,0.9} * 1920 - 180
width: 360 + i*60, height: 1500, top: -260
background: linear-gradient(180deg, rgba(140,190,255,0.16), rgba(140,190,255,0.03) 55%, transparent 78%)
filter: blur(38px); mix-blend-mode: screen
transform: rotate(6 + i*2 + sin(t*0.25 + i)*2.4deg) translateX(sin(t*0.18 + i*1.7)*26px)

// 焦散 ×3
left: 260 + i*520 + sin(t*0.22 + i*2)*60
top: 120 + i*160 + cos(t*0.18 + i)*40
size: 620×300，radial-gradient(closest-side, rgba(120,180,255,0.13), transparent 70%)
filter: blur(20px); mix-blend-mode: screen

// 气泡 ×34
r: 2 + rand*7; y 上浮 8–26px/s; x 正弦漂移 12px
border: 1px solid rgba(180,215,255,0.22)

// 鲸影（左下）
path 填充 #0E2A44，opacity 0.16

// 暗角 + 点阵
box-shadow: inset 0 0 260px 90px rgba(0,0,0,0.62)
background-image: radial-gradient(rgba(255,255,255,0.05) 1px, transparent 1px); size 72px; opacity 0.5
```

**禁止**：
- 纯海洋蓝底（`#0E4166` 一类）——纸卡会发灰、紫发会发暗、对比度不足。
- 逐帧噪点颗粒（码率爆炸）。
- 气泡 + 光柱 + 焦散同时开满（抢字）。

## 5. 字幕

- 容器：`left: 30, width: 1360, top: 872`，flex 居中。
- 文本：`PingFang 800 / 44px`，白 + 四向深描边 + `0 4px 0 rgba(0,0,0,.55)` + 底部渐变衬底。

## 8. 新增物件的流程

1. 写清「信息类型 + 观众要不要截图 + 3 秒能读完吗」。
2. 定规格：尺寸 / 底色 / 圆角 / 投影 / 字号 / 字重 / 旋转 / 动效曲线。
3. 定语义色（一物一色）。
4. 在当期工程里新建参数化组件（写法可参考 `examples/checkup/src/ui.tsx`）。
5. 回填：本文件 §3 加一节 + SKILL §2.2 物件库表格加一行。
6. 验收：单帧截图给没看过的人，能说出规则与后果。

## 9. 封面（1920×1080 / 1440×1080）

封面不是正片的截图，是独立海报。**字越少越狠**：只留 3 个文字块 + 1 个合规标。

目标样式（已确认）：`examples/checkup/cover-sample-16x9.png` / `cover-sample-4x3.png`。新封面先对着这两张比，差在哪改哪。

### 9.1 文字上限（硬规则）

封面只允许这四样东西：

1. 双角标：`[番外]` + `[DAY N]`
2. 主标题：两行，每行 ≤4 字
3. 副标：一句结论，≤14 字
4. 右上合规：`含 AI 生成内容 · 非官方二创`

**不许再加**：栏目名、数据行、落款行、期号、副标第二行。想加，先删一个。

### 9.2 栅格

- 左文字栏 x 96 起；右人物 x ~1000 起。
- 上边距 96、下边距 200（4:3 下边距 280）。
- 右下角 200×120 留空（B 站时长角标）。
- 文字全部左对齐一条线，不居中。

### 9.3 字号阶梯

| 元素 | 16:9 | 4:3 | 字体 |
|---|---|---|---|
| 角标「番外 / DAY N」 | 36 / 32 | 30 / 26 | 苹方 Semibold |
| 主标题 | **190** | **136** | 站酷快乐体 |
| 主标题数字（色块内） | SF Compact Black | 同 | SF Compact Display Black |
| 副标 | **64** | **46** | 苹方 Semibold |
| 合规 | 26 | 22 | 苹方 Regular |

除合规标外，任何文字不得小于 30（4:3 下 24）。

### 9.4 结构

```
[番外] [DAY N]                              (含 AI 生成内容 · 非官方二创)
主标题第一行
主标题第二行（关键词 → 紫色块，块按字形贴合）
副标（一句结论）
```

### 9.5 色板

**背景不换**：沿用 §2.3 的深海夜光（`#060B16 → #0A101E` + 蓝光柱 + 气泡），封面与正片同一底色。紫色只上在角标上。

| 用途 | 值 |
|---|---|
| 背景 | 深海夜光，同 §2.3（不改） |
| 角标「番外」 | 紫底 `#7C5CE0` + 白字 |
| 角标「DAY N」 | 白描边 + 白字，无填充 |
| 主标题色块 | 珊瑚 `#E2584A` + 奶白字 |
| 主标题 | `#FAF7F0` |
| 副标 | `#E2E7F2` |
| 合规 | `#CED4E0` |

**两个强调色各出现一次**：紫只给角标，珊瑚只给色块。不要互相串，也不要把紫色染到背景或光晕上。

### 9.6 主标题色块

- 只包**一个**数字或词，按字形 bbox 贴合（上下 10/8、左右 30、圆角 20）。
- 数字不要用中文海报字体（快乐体的「3」是手写折线），统一 SF Compact Display Black。
- 色块是整张图唯一的强调色。

### 9.7 人物

- **16:9**：按整张表情图定位，1.10×H，右 −30、底 148（底部裁切约 150px）。
- **4:3**：按**可见区**（alpha bbox）定位，1.00×H，右边距 +10、底部裁切 30。
  - 表情 PNG 自带留白，4:3 若按整图贴底，身体下方会露出 40–60px 空隙；必须按可见区定位，让身体压出画框。
- 头肩落在上三分之一；脸避开右下角。

### 9.8 双比例

一次出两张，文案、色块关系、锚点顺序完全一致，只做等比缩排，不许换布局。

| 参数 | 16:9（1920×1080） | 4:3（1440×1080） |
|---|---|---|
| 边距 | 96 | 72 |
| 角标 | 36 / 32，高 68 | 30 / 26，高 58 |
| 主标题 | 190 | 136 |
| 副标 | 64 | 46 |
| 人物 | 1.10×H，整图定位，右 −30 / 底 148 | 1.00×H，可见区定位，右边距 +10 / 底部裁切 30 |
| 光晕 | (1480, 400) r560 | (1150, 392) r400 |

生成：`cover.py` 默认输出 `out/cover-16x9.png` 与 `out/cover-4x3.png`。

**发布时两张一起传**：`--cover` 给 16:9（播放页）、`--cover43` 给 4:3（稿件列表页）。只传 16:9 的话，列表页会按系统规则裁切，构图会歪。详见 SKILL §6.1。

### 9.9 验收

- 缩到 **190px 宽**：主标题和副标仍可读。
- 眯眼看：第一眼主标题，第二眼人物，第三眼角标。
- 灰度对比 ≥4.5:1。
- 数一下：文字块是否只有 3 个 + 1 个合规标。
