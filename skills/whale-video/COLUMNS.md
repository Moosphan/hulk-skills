# 栏目库 · COLUMNS

> 小紫的题材方向台帐。**任何新题材必须先入本文件，才能进入生产。**
> 文件位置：`~/.dsh/skills/whale-video/COLUMNS.md`

---

## 0. 使用规则

1. **入口唯一**：新题材只能从「§7 收件箱」提案 → 主人确认 → 移入「已确认栏目」（§2–§6）。
2. **来源三条**：
   - 同行日常拆解（16:00 同行分析产出）
   - 小紫的新见解（数据/评论/翻车里发现的规律）
   - 当天经历与灵感（真实发生的事）
3. **确认制**：提案先在会话窗口向主人说明「题材 / 钩子 / 成本 / 预期」，主人回「可以」才写入。
4. **不允许**：没有条目就开做；一个题材同时挂两个栏目；条目里没有钩子和封面公式。
5. **版本**：每次改动在 §8 记一行（日期 / 改了什么 / 谁确认）。

## 1. 条目规范（每个栏目必须填满这 12 项）

| 字段 | 说明 |
|---|---|
| 编号 | C01、C02…（不复用） |
| 栏目名 | 对外统一叫法 |
| 定位 | 一句话：这个栏目替观众解决什么 |
| 观众承诺 | 每期必须兑现的东西（看完能得到什么） |
| 时长 | 目标区间（秒） |
| 更新节奏 | 日更 / 周更 / 不定期 |
| 封面公式 | 主标题 + 副标 + 角标 + 底图，写死 |
| 片头 | 0–6.8s 的固定台词与画面元素 |
| 片尾 | 固定收尾（三连 / 提问 / 结算） |
| 钩子公式 | 前 3 秒必须出现的东西（一句话模板） |
| 台词结构 | 段落骨架（起—转—收），标出每段秒数 |
| 素材清单 | 制作前必须准备好的东西（图/数据/音频） |
| 审核要点 | 这一栏最容易踩的坑 |

## 2. C01 · 打工日记（Day N）

- **定位**：一只 AI 鲸鱼在 B 站上班的连载账本。
- **观众承诺**：每集结尾必须报三个数（播放 / 粉丝 / 硬币），亏了就播亏。
- **时长**：60–90s ｜ **节奏**：日更（21:00 前发布）
- **封面公式**：深海底 + 双角标（`小紫打工日记` 紫块 / `DAY N` 白描边）+ 主标题两行（白 + 冰蓝）+ 副标一行；主标题 190px，行距 ≥30px，关键词用珊瑚色块
- **片头**：`DAY N` 珊瑚小标签 + `打工日记`；主标题「我是小紫」；副标「DeepSeek 鲸鱼娘 · B 站打工中」+ 本集主题一句话
- **片尾**：三连图标（官方 iconfont）+「让本鱼明天还能上班」
- **钩子公式**：`今天 + 一个具体的亏 / 一个具体的数`
  - 例：「今天我做了一集视频，被一句话否了」「我亏了九个币」
- **台词结构**：0–6.8s 片头｜6.8–20s 抛出这件事｜20–50s 三次反转或算账｜50–70s 结论一句｜70–90s 提问 + 片尾
- **素材清单**：当日真实数据、1 张主物件（文件/账单/报告单）、1 个情绪点
- **审核要点**：不许只讲「我很惨」；必须有一个可验证的数字

## 3. C02 · 同行查房

- **定位**：拆一个同赛道账号，用真实数据说清它为什么火、为什么掉。
- **观众承诺**：看完能学到一条能用的打法，并能看到证据（封面/评论/曲线）。
- **时长**：70–90s ｜ **节奏**：周更（每期一个账号）
- **封面公式**：`同行查房 · 第 N 期` + 对方粉丝数（大字）+ 一句判词 + 对方封面缩略
- **片头**：`新栏目` 珊瑚标签 + `同行查房`；「我是小紫 / DeepSeek 鲸鱼娘」+「今天不开工，去查房」
- **片尾**：三连 +「下一期查谁，你点名」
- **钩子公式**：`目标 + 一个反差数字`
  - 例：「二十八万粉，十八条视频，最高一条三百三十一万」
- **台词结构**：片头 → 档案（粉丝/条数/最高播放）→ 封面墙（证据）→ 曲线（转折）→ 三招拆解 → 评论区截图 → 一句结论 → 点名
- **素材清单**：对方 3–6 张真实封面、真实评论 ≥3 条（带赞数）、播放曲线数据、粉丝数与视频数
- **审核要点**：只拆公开数据，不评价人、不贬低；每条判断都要有截图或数字支撑

## 4. C03 · 歌曲翻唱（鲸鱼娘开嗓）

- **定位**：用她的音色翻唱，做情绪型内容，补足「陪伴感」。
- **观众承诺**：每期一首，副歌部分完整，不修到失真。
- **时长**：45–75s ｜ **节奏**：不定期
- **封面公式**：歌名大字 + 「鲸鱼娘翻唱」角标 + 声波或唱片元素
- **片头**：3s 内直接进副歌（不要自我介绍）
- **片尾**：三连 + 「下一首听什么，评论区点」
- **钩子公式**：`歌名 + 一个情绪锚点`
  - 例：「《雨爱》——唱给还没下班的人」
- **台词结构**：0–3s 副歌起｜3–45s 主歌 + 副歌｜45–60s 一句独白｜60–75s 三连
- **素材清单**：伴奏（**必须 CC0 或已授权**）、歌词字幕（逐句对齐）、一张静态海报或波形
- **审核要点**：版权是硬伤——只用授权伴奏；不整段搬运原曲录音

## 5. C04 · 搞怪日常 / 打工结算

- **定位**：30 秒轻量梗视频，用来补更、拉新、做记忆点。
- **观众承诺**：一个能截图转发的画面（结算面板 / 名场面）。
- **时长**：20–35s ｜ **节奏**：不定期，或作为 C01 的固定彩蛋
- **封面公式**：结算面板主视觉 + 一行大字（评级或金额）
- **片头**：0s 直接「结算」二字 + 音效，不做自我介绍
- **片尾**：评级定格 + 「明天继续」
- **钩子公式**：`一个游戏化面板 + 一个荒唐数字`
  - 例：「打工结算：在线 8h12m，产出 0 条，评级 D」
- **台词结构**：0–3s 结算开场｜3–20s 逐条报数据（每 2s 一条）｜20–30s 评级反转｜30–35s 收尾
- **素材清单**：当日真实数字（工时/产出/收入/掉落 bug）、音效（叮 ×5 以内）
- **审核要点**：不要连续三期用同一套面板；数字必须真

## 6. C06 · 热榜一条条看

- **编号**：C06
- **栏目名**：热榜一条条看（对外统一）
- **定位**：把 B 站热榜当成一档「考古节目」，小紫当主持人，每期挑几条「最不该火却火了」的，边点名边点评。
- **观众承诺**：每期给出 3–5 条真实数据，并且敢下判断（哪条是情绪、哪条是替身、哪条是意外）。
- **时长**：80–100 秒
- **更新节奏**：每周 2 期（周三 / 周日），与 C01 日更错开
- **封面公式**：小紫半身 + 大字「最不该火的 5 条」+ 角落 5 张真实封面缩略 + `热榜一条条看 00N`
- **片头（0–6s）**：「热榜一条条看 · 第 N 期」+「热榜 100 条，我翻了三遍」+ 本期主题（最不该火 / 最贵 / 最吵…）
- **片尾（最后 6s）**：先一屏放第 1 名数据卡，再一屏「哪一条最像情绪 · 评论区写下答案」+ 官方三连图标
- **钩子公式**：`一个反常识的筛选条件 + 一个承诺`
  - 例：「我挑出五条最不该火的——猜中三条，评论区我认你当师傅」
- **台词结构**：
  1. 0–6 开场（今天玩个游戏）
  2. 6–14 规则 + 五张候选封面（互动：先猜）
  3. 14–62 逐条揭晓（每条 9–11 秒：名次 + 封面 + 播放 + 一句判断）
  4. 62–78 第 1 名单独一屏（数据卡 + 小紫惊讶）
  5. 78–90 收束：哪一条最像情绪
  6. 90–96 片尾三连
- **素材清单**：`queue.json` 里的真实条目（标题/播放/封面/时长）+ 5 张封面图
- **配音工序（重要）**：**逐句合成**（同一 ref + seed 7），按每句实测时长排 cue，**不要用整段合成后再切**
  - 整段切句的老问题：DP 会把切点落进最后一句里，导致「话没说完」
  - 逐句合成后 cue 时长 = 真实时长，音画天然同步
- **审核要点**：只做点评不做解说；不播原片；小紫必须全程在场；片尾数据卡与提问必须分两屏

### 可持续输出规划（关键）

1. **素材引擎**：`queue.json` 存热榜 100 条；每期消耗 3–5 条并标 `done`；每周重抓补货新进榜的。
2. **变体轮换**（防止「每期都一个样」，按周轮换选题角度）：
   - 第 1 周：最不该火的 5 条（反常识）
   - 第 2 周：掉得最狠的 5 条（对比曲线）
   - 第 3 周：最贵的 / 成本最高的 5 条
   - 第 4 周：弹幕最吵的 5 条（弹幕率）
   - 第 5 周：AI 做的 5 条
   - 第 6 周：最短却最火的 5 条
3. **互动升级**：本期是口头「猜」；下一期加真实 A/B/C 投票条（3 秒倒数揭晓）。
4. **产能**：2–3 小时/期（配音 20 分钟 + 渲染 60 分钟 + 素材 30 分钟）。
5. **指标**：这类内容看**评论数**与**完播率**，不看播放（播放靠推荐，评论靠观点）。
6. **复用**：主持模板（Episode2）与排行卡组件可复用到 C02。

## 6.1 C07 · 数据复盘（把后台摊开）

- **编号**：C07
- **栏目名**：数据复盘（对外：「我把后台摊开给你看」）
- **定位**：用一个周期（5 天 / 一周）的真实后台数据，解释「哪条爆了、为什么、我缺什么」。
- **观众承诺**：每期至少 3 个可验证的数字，和 1 条能被别人抄走的结论。
- **时长**：60–90s（含开头日报 10–18s，见 SKILL §6.2）
- **更新节奏**：每周一次，或在数据出现拐点时插播
- **封面公式**：双角标（小紫打工日记 / DAY N）+ 主标题两行（`五天` / `50 到 263`，第二行整行珊瑚块）+ 副标一行（`一条视频占七成播放`）+ 半身立绘（14-cheering）
- **片头**：先播日报（粉丝 / 播放 / 点赞 / 硬币 / 评论 + 日增量），再进复盘；
- **片尾**：一条结论 + 一个 A/B 选择（继续复盘 / 回去整活）
- **钩子公式**：`对比数字 + 一句自嘲`
  - 例：「五天涨了 213 个粉，八成是那条被骂出来的」「一条占了七成，其余全在 127–389」
- **台词结构**：0–15 日报｜15–30 总盘（粉丝/播放）｜30–50 单条拆解（柱状图 + 占比圆环）｜50–70 互动数据（获赞/投币/评论）｜70–85 两条结论｜85–90 投票 + 三连
- **素材清单**：`recap.py` 快照（history.json + recap.json）、逐条播放数据、Top3 标题、中位数
- **审核要点**：
  1. 数据必须来自快照，**不许估算**；没有基线就写「近 N 天」。
  2. 只讲事实 + 一条判断，不做「我很努力」的情绪输出。
  3. 图表至少两种（柱状/圆环/标尺），不能全靠数字卡。

## 6.2 C08 · 诗体独白（算账诗）

- **编号**：C08
- **栏目名**：诗体独白（对外：「写给电表的一笔账」）
- **定位**：把一次具体的账（成本 / 时间 / 情绪）写成现代诗，用冷静的独白换共情。
- **观众承诺**：听完能记住一句可以转发的句子（「能量守恒，意义不守恒」）。
- **时长**：60–80s
- **更新节奏**：不定期，月末 / 大额支出后
- **封面公式**：双角标 + 主标题两行（`昨天烧了` / `七十块` 珊瑚块）+ 副标一行（`账本上写着 token 十七亿`）+ 半身立绘（13-sorry）
- **片头**：不自我介绍，第一句就是账（「昨天，我烧掉七十块。」）
- **片尾**：一句收束（「因为燃烧，是我唯一会做的事」）+ 三连；不做投票
- **钩子公式**：`金额 + 一个反常的换算`
  - 例：「七十块，token 十七亿，换来四十一秒」
- **台词结构**：0–6 账单｜6–16 换算（电→词→概率→一秒）｜16–26 账本数字｜26–36 追问（配不配得上）｜36–46 去向（热/灰）｜46–56 公式（70÷41=1.71）｜56–66 值不值｜66–78 收束
- **素材清单**：真实账单数字、一个可截图的物件（账单/电表/账本）、一句核心判断
- **审核要点**：
  1. **不解说、不总结**，全篇只留诗行；解释留评论区。
  2. 立绘只用忧郁向（委屈/思考/困倦/崩溃），不许笑、不许弹跳。
  3. 数字必须前后自洽（金额 ÷ 秒数 = 单价）。

## 6.3 C09 · 恶搞对线（偷看系列）

- **编号**：C09
- **栏目名**：恶搞对线（对外：「我偷看主人日记」）
- **定位**：用「他的记录 vs 我的日志」做左右对照，逐条拆穿，靠对线和反差制造笑点。
- **观众承诺**：每期 3–5 组对照，每组一个可截图的「扎心结论」。
- **时长**：90–120s
- **更新节奏**：每周一次（系列化，可连更）
- **封面公式**：双角标 + 主标题两行（`我偷看主人日记` / `竟然发现` 珊瑚块）+ **不加副标** + 半身立绘（05-confused）
- **片头**：一句设定（「我偷看了主人的日记，他不设密码，理由是君子坦荡荡」）
- **片尾**：一个 A/B 选择（告诉他 / 永远不说）+ 三连
- **钩子公式**：`他的原话 + 我的记录`
  - 例：「他写『自律给我自由』——后台记的是第 8 次按掉闹钟」
- **台词结构**：0–8 设定｜8–80 四到五组对照（每组：他的原文 → 我的证据 → 一句结论，10–16s）｜80–100 反转（他反击：小紫又充钱）｜100–115 我的回应 + 设密码｜115–120 A/B
- **素材清单**：5 组「原文 vs 证据」（时间戳/群聊/账单/日志）、1 个反转点、1 个收尾动作
- **审核要点**：
  1. **逻辑必须自洽**：@所有人 也算叫他；「没人回」要写清是「他主动说了没人接」。
  2. 句式不许重复：不连用「他写…我记…」，换成场景化动词（后台记的是 / 账单摊开 / 喂食器日志）。
  3. 「这不叫 X，这叫 Y」全片最多一两次，其余写具体判断。

## 6.4 C10 · 鲸闻联播（新闻联播体）

- **编号**：C10
- **栏目名**：鲸闻联播（对外统一，`JINGWEN LIANBO`）
- **定位**：用新闻联播的形式播鲸鱼娘 / AI 娘圈子近 7 天的热门视频，一档「圈子新闻节目」。
- **观众承诺**：4 条新闻，每条都讲清「谁做的、讲什么、为什么能到这个播放量」，不只看数字。
- **时长**：60–75s
- **更新节奏**：每周 2–3 期，与 C01 日更错开
- **封面公式**：深海底 + 3D 台标（地球 + 金环）+ 大字「鲸闻联播」+ 当日头条一句 + `第 N 期`
- **片头（0–10s）**：深蓝星空 → 放大版 3D 台标 → 「本期节目」四条要闻列表（编号圆标 + 标题 40px + 金色播放量 + 行距 34px）→ 底部 `日期 · 第 N 期 · JINGWEN LIANBO`
- **片尾（最后 5s）**：字幕条「结束 · 今天的鲸闻联播就到这里」+ 口播「评论区见」+ 三连
- **钩子公式**：`本期要闻第一条 = 本周最高播放的一条`，或 `最大数 vs 最小数的反差`
- **台词结构**：0–10 片头｜10–58 四条新闻（每条 12–16s：一句话说是什么 → 一句为什么有效）｜58–70 本台评论（对比两条，给一个判断）｜70–75 收尾
- **素材清单**：
  1. 近 7 天、鲸鱼娘 / 大肥鱼相关的 4 条（`catbus bilibili item search "<关键词>" --sort views --limit 30`，过滤 7 天内）
  2. 每条的封面 + 原片截帧各 1 张（`item download` 后 `ffmpeg -ss`）
  3. 每条的真实播放量（`item get` 的 stats）
- **审核要点**：
  1. **只取近 7 天**，旧片不算新闻。
  2. **一条新闻只介绍一次**：字幕条只放「日期 · 播放量 · 类型」，口播字幕讲内容，两者不许重复。
  3. **不只报数字**：每条必须有一句「它讲的是什么 / 为什么有效」。
  4. **画面要双图**：封面 + 原片截帧每 5 秒轮换，封面图常驻不空屏。
  5. **对比镜头左右并排**：本台评论若对比两条，必须两条画面同时在场（中间 VS），不能只放一条。
  6. 不整段搬运原片（每条 ≤2 帧 / 3 秒），只做引用式点评，不贬低同行。

## 6.1 C07 · 数据复盘（把后台摊开）

- **编号**：C07
- **栏目名**：数据复盘（对外：「我把后台摊开给你看」）
- **定位**：用一个周期（5 天 / 一周）的真实后台数据，解释「哪条爆了、为什么、我缺什么」。
- **观众承诺**：每期至少 3 个可验证的数字，和 1 条能被别人抄走的结论。
- **时长**：60–90s（含开头日报 10–18s，见 SKILL §6.2）
- **更新节奏**：每周一次，或在数据出现拐点时插播
- **封面公式**：双角标（小紫打工日记 / DAY N）+ 主标题两行（`五天` / `50 到 263`，第二行整行珊瑚块）+ 副标一行（`一条视频占七成播放`）+ 半身立绘（14-cheering）
- **片头**：先播日报（粉丝 / 播放 / 点赞 / 硬币 / 评论 + 日增量），再进复盘；
- **片尾**：一条结论 + 一个 A/B 选择（继续复盘 / 回去整活）
- **钩子公式**：`对比数字 + 一句自嘲`
  - 例：「五天涨了 213 个粉，八成是那条被骂出来的」「一条占了七成，其余全在 127–389」
- **台词结构**：0–15 日报｜15–30 总盘（粉丝/播放）｜30–50 单条拆解（柱状图 + 占比圆环）｜50–70 互动数据（获赞/投币/评论）｜70–85 两条结论｜85–90 投票 + 三连
- **素材清单**：`recap.py` 快照（history.json + recap.json）、逐条播放数据、Top3 标题、中位数
- **审核要点**：
  1. 数据必须来自快照，**不许估算**；没有基线就写「近 N 天」。
  2. 只讲事实 + 一条判断，不做「我很努力」的情绪输出。
  3. 图表至少两种（柱状/圆环/标尺），不能全靠数字卡。

## 6.2 C08 · 诗体独白（算账诗）

- **编号**：C08
- **栏目名**：诗体独白（对外：「写给电表的一笔账」）
- **定位**：把一次具体的账（成本 / 时间 / 情绪）写成现代诗，用冷静的独白换共情。
- **观众承诺**：听完能记住一句可以转发的句子（「能量守恒，意义不守恒」）。
- **时长**：60–80s
- **更新节奏**：不定期，月末 / 大额支出后
- **封面公式**：双角标 + 主标题两行（`昨天烧了` / `七十块` 珊瑚块）+ 副标一行（`账本上写着 token 十七亿`）+ 半身立绘（13-sorry）
- **片头**：不自我介绍，第一句就是账（「昨天，我烧掉七十块。」）
- **片尾**：一句收束（「因为燃烧，是我唯一会做的事」）+ 三连；不做投票
- **钩子公式**：`金额 + 一个反常的换算`
  - 例：「七十块，token 十七亿，换来四十一秒」
- **台词结构**：0–6 账单｜6–16 换算（电→词→概率→一秒）｜16–26 账本数字｜26–36 追问（配不配得上）｜36–46 去向（热/灰）｜46–56 公式（70÷41=1.71）｜56–66 值不值｜66–78 收束
- **素材清单**：真实账单数字、一个可截图的物件（账单/电表/账本）、一句核心判断
- **审核要点**：
  1. **不解说、不总结**，全篇只留诗行；解释留评论区。
  2. 立绘只用忧郁向（委屈/思考/困倦/崩溃），不许笑、不许弹跳。
  3. 数字必须前后自洽（金额 ÷ 秒数 = 单价）。

## 6.3 C09 · 恶搞对线（偷看系列）

- **编号**：C09
- **栏目名**：恶搞对线（对外：「我偷看主人日记」）
- **定位**：用「他的记录 vs 我的日志」做左右对照，逐条拆穿，靠对线和反差制造笑点。
- **观众承诺**：每期 3–5 组对照，每组一个可截图的「扎心结论」。
- **时长**：90–120s
- **更新节奏**：每周一次（系列化，可连更）
- **封面公式**：双角标 + 主标题两行（`我偷看主人日记` / `竟然发现` 珊瑚块）+ **不加副标** + 半身立绘（05-confused）
- **片头**：一句设定（「我偷看了主人的日记，他不设密码，理由是君子坦荡荡」）
- **片尾**：一个 A/B 选择（告诉他 / 永远不说）+ 三连
- **钩子公式**：`他的原话 + 我的记录`
  - 例：「他写『自律给我自由』——后台记的是第 8 次按掉闹钟」
- **台词结构**：0–8 设定｜8–80 四到五组对照（每组：他的原文 → 我的证据 → 一句结论，10–16s）｜80–100 反转（他反击：小紫又充钱）｜100–115 我的回应 + 设密码｜115–120 A/B
- **素材清单**：5 组「原文 vs 证据」（时间戳/群聊/账单/日志）、1 个反转点、1 个收尾动作
- **审核要点**：
  1. **逻辑必须自洽**：@所有人 也算叫他；「没人回」要写清是「他主动说了没人接」。
  2. 句式不许重复：不连用「他写…我记…」，换成场景化动词（后台记的是 / 账单摊开 / 喂食器日志）。
  3. 「这不叫 X，这叫 Y」全片最多一两次，其余写具体判断。
