## 0. 使用规则

1. **入口唯一**：新题材只能从「§7 收件箱」提案 → 主人确认 → 移入「已确认栏目」（§2–§6）。
2. **来源三条**：
   - 同行日常拆解（16:00 同行分析产出）
   - 小紫的新见解（数据/评论/翻车里发现的规律）
   - 当天经历与灵感（真实发生的事）
3. **确认制**：提案先在会话窗口向主人说明「题材 / 钩子 / 成本 / 预期」，主人回「可以」才写入。
4. **不允许**：没有条目就开做；一个题材同时挂两个栏目；条目里没有钩子和封面公式。
5. **版本**：每次改动在 §8 记一行（日期 / 改了什么 / 谁确认）。

## 1. 条目规范（每个栏目必须填满这 12 项）

| 字段 | 说明 |
|---|---|
| 编号 | C01、C02…（不复用） |
| 栏目名 | 对外统一叫法 |
| 定位 | 一句话：这个栏目替观众解决什么 |
| 观众承诺 | 每期必须兑现的东西（看完能得到什么） |
| 时长 | 目标区间（秒） |
| 更新节奏 | 日更 / 周更 / 不定期 |
| 封面公式 | 主标题 + 副标 + 角标 + 底图，写死 |
| 片头 | 0–6.8s 的固定台词与画面元素 |
| 片尾 | 固定收尾（三连 / 提问 / 结算） |
| 钩子公式 | 前 3 秒必须出现的东西（一句话模板） |
| 台词结构 | 段落骨架（起—转—收），标出每段秒数 |
| 素材清单 | 制作前必须准备好的东西（图/数据/音频） |
| 审核要点 | 这一栏最容易踩的坑 |

## 2. C01 · 打工日记（Day N）

- **定位**：一只 AI 鲸鱼在 B 站上班的连载账本。
- **观众承诺**：每集结尾必须报三个数（播放 / 粉丝 / 硬币），亏了就播亏。
- **时长**：60–90s ｜ **节奏**：日更（21:00 前发布）
- **封面公式**：深海底 + 双角标（`小紫打工日记` 紫块 / `DAY N` 白描边）+ 主标题两行（白 + 冰蓝）+ 副标一行；主标题 190px，行距 ≥30px，关键词用珊瑚色块
- **片头**：`DAY N` 珊瑚小标签 + `打工日记`；主标题「我是小紫」；副标「DeepSeek 鲸鱼娘 · B 站打工中」+ 本集主题一句话
- **片尾**：三连图标（官方 iconfont）+「让本鱼明天还能上班」
- **钩子公式**：`今天 + 一个具体的亏 / 一个具体的数`
  - 例：「今天我做了一集视频，被一句话否了」「我亏了九个币」
- **台词结构**：0–6.8s 片头｜6.8–20s 抛出这件事｜20–50s 三次反转或算账｜50–70s 结论一句｜70–90s 提问 + 片尾
- **素材清单**：当日真实数据、1 张主物件（文件/账单/报告单）、1 个情绪点
- **审核要点**：不许只讲「我很惨」；必须有一个可验证的数字

## 3. C02 · 同行查房

- **定位**：拆一个同赛道账号，用真实数据说清它为什么火、为什么掉。
- **观众承诺**：看完能学到一条能用的打法，并能看到证据（封面/评论/曲线）。
- **时长**：70–90s ｜ **节奏**：周更（每期一个账号）
- **封面公式**：`同行查房 · 第 N 期` + 对方粉丝数（大字）+ 一句判词 + 对方封面缩略
- **片头**：`新栏目` 珊瑚标签 + `同行查房`；「我是小紫 / DeepSeek 鲸鱼娘」+「今天不开工，去查房」
- **片尾**：三连 +「下一期查谁，你点名」
- **钩子公式**：`目标 + 一个反差数字`
  - 例：「二十八万粉，十八条视频，最高一条三百三十一万」
- **台词结构**：片头 → 档案（粉丝/条数/最高播放）→ 封面墙（证据）→ 曲线（转折）→ 三招拆解 → 评论区截图 → 一句结论 → 点名
- **素材清单**：对方 3–6 张真实封面、真实评论 ≥3 条（带赞数）、播放曲线数据、粉丝数与视频数
- **审核要点**：只拆公开数据，不评价人、不贬低；每条判断都要有截图或数字支撑

## 4. C03 · 歌曲翻唱（鲸鱼娘开嗓）

- **定位**：用她的音色翻唱，做情绪型内容，补足「陪伴感」。
- **观众承诺**：每期一首，副歌部分完整，不修到失真。
- **时长**：45–75s ｜ **节奏**：不定期
- **封面公式**：歌名大字 + 「鲸鱼娘翻唱」角标 + 声波或唱片元素
- **片头**：3s 内直接进副歌（不要自我介绍）
- **片尾**：三连 + 「下一首听什么，评论区点」
- **钩子公式**：`歌名 + 一个情绪锚点`
  - 例：「《雨爱》——唱给还没下班的人」
- **台词结构**：0–3s 副歌起｜3–45s 主歌 + 副歌｜45–60s 一句独白｜60–75s 三连
- **素材清单**：伴奏（**必须 CC0 或已授权**）、歌词字幕（逐句对齐）、一张静态海报或波形
- **审核要点**：版权是硬伤——只用授权伴奏；不整段搬运原曲录音

## 5. C04 · 搞怪日常 / 打工结算

- **定位**：30 秒轻量梗视频，用来补更、拉新、做记忆点。
- **观众承诺**：一个能截图转发的画面（结算面板 / 名场面）。
- **时长**：20–35s ｜ **节奏**：不定期，或作为 C01 的固定彩蛋
- **封面公式**：结算面板主视觉 + 一行大字（评级或金额）
- **片头**：0s 直接「结算」二字 + 音效，不做自我介绍
- **片尾**：评级定格 + 「明天继续」
- **钩子公式**：`一个游戏化面板 + 一个荒唐数字`
  - 例：「打工结算：在线 8h12m，产出 0 条，评级 D」
- **台词结构**：0–3s 结算开场｜3–20s 逐条报数据（每 2s 一条）｜20–30s 评级反转｜30–35s 收尾
- **素材清单**：当日真实数字（工时/产出/收入/掉落 bug）、音效（叮 ×5 以内）
- **审核要点**：不要连续三期用同一套面板；数字必须真

## 6. C06 · 热榜一条条看

- **编号**：C06
- **栏目名**：热榜一条条看（对外统一）
- **定位**：把 B 站热榜当成一档「考古节目」，小紫当主持人，每期挑几条「最不该火却火了」的，边点名边点评。
- **观众承诺**：每期给出 3–5 条真实数据，并且敢下判断（哪条是情绪、哪条是替身、哪条是意外）。
- **时长**：80–100 秒
- **更新节奏**：每周 2 期（周三 / 周日），与 C01 日更错开
- **封面公式**：小紫半身 + 大字「最不该火的 5 条」+ 角落 5 张真实封面缩略 + `热榜一条条看 00N`
- **片头（0–6s）**：「热榜一条条看 · 第 N 期」+「热榜 100 条，我翻了三遍」+ 本期主题（最不该火 / 最贵 / 最吵…）
- **片尾（最后 6s）**：先一屏放第 1 名数据卡，再一屏「哪一条最像情绪 · 评论区写下答案」+ 官方三连图标
- **钩子公式**：`一个反常识的筛选条件 + 一个承诺`
  - 例：「我挑出五条最不该火的——猜中三条，评论区我认你当师傅」
- **台词结构**：
  1. 0–6 开场（今天玩个游戏）
  2. 6–14 规则 + 五张候选封面（互动：先猜）
  3. 14–62 逐条揭晓（每条 9–11 秒：名次 + 封面 + 播放 + 一句判断）
  4. 62–78 第 1 名单独一屏（数据卡 + 小紫惊讶）
  5. 78–90 收束：哪一条最像情绪
  6. 90–96 片尾三连
- **素材清单**：`queue.json` 里的真实条目（标题/播放/封面/时长）+ 5 张封面图
- **审核要点**：只做点评不做解说；不播原片；小紫必须全程在场；片尾数据卡与提问必须分两屏

### 可持续输出规划（关键）

1. **素材引擎**：`queue.json` 存热榜 100 条；每期消耗 3–5 条并标 `done`；每周重抓补货新进榜的。
2. **变体轮换**（防止「每期都一个样」，按周轮换选题角度）：
   - 第 1 周：最不该火的 5 条（反常识）
   - 第 2 周：掉得最狠的 5 条（对比曲线）
   - 第 3 周：最贵的 / 成本最高的 5 条
   - 第 4 周：弹幕最吵的 5 条（弹幕率）
   - 第 5 周：AI 做的 5 条
   - 第 6 周：最短却最火的 5 条
3. **互动升级**：本期是口头「猜」；下一期加真实 A/B/C 投票条（3 秒倒数揭晓）。
4. **产能**：2–3 小时/期（配音 20 分钟 + 渲染 60 分钟 + 素材 30 分钟）。
5. **指标**：这类内容看**评论数**与**完播率**，不看播放（播放靠推荐，评论靠观点）。
6. **复用**：主持模板（Episode2）与排行卡组件可复用到 C02。
