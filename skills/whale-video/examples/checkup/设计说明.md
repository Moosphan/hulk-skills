# 小紫 · 番外《AI 员工年度体检》设计说明

## 1. 为什么选这个题

三条标准：**能吸引流量、单人可做、物件丰富**。

- **流量**：体检是"可验证的评测"——观众天然想知道 AI 到底哪项不行；同时踩中"年度报告季"和 AI 测评两个流量池。
- **单人可做**：不需要多账号对打，把参考视频的"淘汰赛"换成"及格线"，张力一样，成本减半。
- **物件丰富**：体检天然带一整套道具——红头通知、项目表、答题卡、参考文献、上下文窗口、空气样本、监控画面、心率图、报告单、印章。

## 2. 和参考视频的结构对照

| 参考视频（干饭鱼 Day 0） | 本片 |
|---|---|
| 工牌：3 秒交代身份与赛制 | 片头：身份 + "今天体检" |
| 入职合同：把规则变成 HR 文件 | 红头文件：五项、挂两项优化 |
| 四工位：可视化竞争对手 | 五项测试：把"对手"换成"及格线" |
| 嘴硬 → 翻车 → 认账 | 9.11 → 不合格 → 补考摸鱼 |
| 三选一投票 + 关注=保命 | 三选一 + 三连=明天还能上班 |

**共同点**：每 4–6 秒一个新物件；规则用一件实物说清；结尾把"关注"翻译成剧情内的行为。

## 3. 视觉系统（本片新增）

- **背景：深海夜光**，不是"海洋蓝"。
  - 底色 `#0A1322 → #05080F`，四道缓慢摆动的光柱 + 三团焦散光斑 + 34 颗上浮气泡 + 远处鲸影。
  - 理由：白纸道具需要暗底才立得住；纯海洋蓝（`#0E4166`）会把纸卡洗灰、把紫发压暗。海洋感靠"光"和"动"，不靠"蓝"。
- **纸感道具**：暖白 `#F8F4E9` + 墨色字 + 红色抬头/印章；每张卡片一个信息点，可单独截图。
- **语义色**：算术=珊瑚、幻觉=琥珀、记忆=蓝、情商=薄荷、摸鱼=金——颜色跟着"项目"走，一屏不超过两种。
- **人物**：右侧常驻，用 20 张表情素材里的 10 张，逐场换表情；上下浮动 9px 模拟呼吸。

表情使用表：

## 4. 声音

- 配音：edge-tts `zh-CN-XiaoyiNeural`，rate `-2%`、pitch `+8Hz`（系列冻结参数）
- BGM：Carefree — Kevin MacLeod，CC BY 4.0，音量 0.15，首尾淡入淡出
- SFX：印章 / 叮 / 错误 / 弹入 / 翻页 / whoosh，全部本地合成，无版权问题
- 响度：loudnorm −16 LUFS，真峰值 −4.4 dBFS；人声与 BGM 动态差约 20 dB

## 5. 工程

- Remotion 4.0.539，1920×1080 / 30fps / 2665 帧 / 88.85s
- 时间轴由 `build_audio.py` 生成（TTS 实测时长 → cue 表 → 场景边界），画面与口播天然对齐
- QA：平均帧差 5.1、硬切 0（阈值 70）、最低亮度 12.4（无黑帧）

## 6. 还能更好

1. **片中留白**：s0 片头 7 秒只有标题，可以再加一个"体检表盖章"的小动作。
2. **对手感**：单人没有对手戏，下一集可以把"及格线"人格化成一个"体检医生"角色（画外音）。
3. **数据真实度**：本集的分数是设定值；如果开"真测"系列（现场跑题），可信度和传播力会更高。
